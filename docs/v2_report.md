# Hide-and-Seek RL V2 — บันทึกการทดลอง

## เป้าหมาย

ต่อจาก [V1](report.md) ที่ฝึก Seeker กับ Hider เดินสุ่ม V2 ฝึก Hider ให้หลบและฝึก Seeker ให้รับมือกับ Hider ที่เรียนรู้แล้ว โมเดล V1 ถูกเก็บไว้เพื่อเป็นคู่เทียบ การทดลองยังใช้สนามเปิด 8 × 8, 64 ก้าวต่อ episode และการมองเห็นตำแหน่งทั้งสองฝ่ายตลอด

## สภาพแวดล้อมและรางวัล

Observation มี 8 ค่าเหมือน V1 แต่เรียง **ตำแหน่งตัวเองก่อนคู่แข่ง** ตามบทบาทที่กำลังฝึก ตามด้วยระยะถึงขอบ 4 ด้านของตัวเอง Action มี 4 ทิศทาง ทั้งสองฝ่ายตัดสินใจจากสถานะต้นก้าวเดียวกัน แล้วระบบให้ Seeker เดินก่อน Hider ถ้า Seeker เข้าไปในช่อง Hider จะจับได้ก่อน Hider มีโอกาสเดินในก้าวนั้น

Seeker ได้ `+1` เมื่อจับได้, `-1` เมื่อครบเวลา, `-0.01` ระหว่างทาง Hider ได้ `-1` เมื่อถูกจับ, `+1` เมื่อรอดครบเวลา, `+0.01` ระหว่างทาง `success` ใน log ของ Hider จึงหมายถึง **รอดครบเวลา** ส่วน log ของ Seeker หมายถึง **จับได้**

## วิธีฝึก

ใช้ PPO `MlpPolicy` ผ่าน Stable-Baselines3, rollout 512, batch size 64, training seed 42 เริ่ม Seeker จากโมเดล V1 และ Hider จากโมเดลใหม่ ฝึก 2 รอบ รอบละ Hider 50,000 ก้าวกับ Seeker ที่ตรึงไว้ แล้ว Seeker 50,000 ก้าวกับ Hider ที่ตรึงไว้ รวมขอฝึก 100,000 ก้าวต่อฝ่าย; เนื่องจาก PPO ทำงานเป็น rollout จริงจึงฝึกเพิ่มฝ่ายละ 100,352 ก้าว Seeker V2 มีจำนวนก้าวสะสม 200,704 ก้าวเมื่อรวม V1

| ช่วงฝึก | จำนวน episode ที่จบ | Success ตลอดช่วง | Success 100 episode ท้าย |
| --- | ---: | ---: | ---: |
| Hider รอบ 1 | 3,678 | 7.5% | 36% |
| Seeker รอบ 1 | 7,751 | 100% | 100% |
| Hider รอบ 2 | 3,985 | 8.2% | 35% |
| Seeker รอบ 2 | 6,790 | 99.7% | 100% |

ผลระหว่างฝึกขึ้นกับคู่แข่งในรอบนั้น จึงไม่ใช้แทนผลประเมินอิสระ ไฟล์ราย episode อยู่ใน `results/v2_hider_round_*.csv` และ `results/v2_seeker_round_*.csv`

## วิธีประเมิน

ตรึงโมเดลทุกฝ่าย ใช้ action แบบ deterministic สำหรับโมเดล PPO ประเมิน 3 กลุ่ม seed: 1000–1099, 2000–2099, 3000–3099 รวม 300 episode ต่อคู่ รายงานอัตราที่ Seeker จับได้และจำนวนก้าวเฉลี่ยก่อนจบเกม ทั้ง 6 คู่ใช้กติกาเดียวกันและจุดเริ่มที่ได้จาก seed เดียวกันในแต่ละ episode ผลรายรอบอยู่ใน `results/v2_evaluation.csv` และ [กราฟ](../results/v2_metrics.png) ซึ่งแถบความคลาดเคลื่อนแสดงส่วนเบี่ยงเบนมาตรฐานของค่าเฉลี่ยระหว่าง 3 กลุ่ม seed

| Seeker / Hider | Seeker จับได้ | Hider รอด | ก้าวเฉลี่ย |
| --- | ---: | ---: | ---: |
| สุ่ม / สุ่ม | 191/300 (63.7%) | 109/300 (36.3%) | 39.28 |
| สุ่ม / Hider V2 | 50/300 (16.7%) | 250/300 (83.3%) | 58.84 |
| Seeker V1 / สุ่ม | 300/300 (100%) | 0/300 | 5.41 |
| Seeker V1 / Hider V2 | 290/300 (96.7%) | 10/300 (3.3%) | 9.90 |
| Seeker V2 / สุ่ม | 300/300 (100%) | 0/300 | 5.29 |
| Seeker V2 / Hider V2 | 300/300 (100%) | 0/300 | 6.43 |

เมื่อเจอ Seeker สุ่ม Hider V2 รอดมากกว่า Hider สุ่ม 141 รอบจาก 300 รอบ เมื่อเจอ Seeker V1 ที่แข็งแรง Hider V2 ยังรอดได้น้อย แต่ยืดเวลาเฉลี่ยจาก 5.41 เป็น 9.90 ก้าว Seeker V2 รับมือกับ Hider V2 ได้ดีขึ้นเมื่อเทียบกับ Seeker V1: จับได้ 300 แทน 290 รอบ และใช้เวลาเฉลี่ย 6.43 แทน 9.90 ก้าว

## ข้อจำกัด

- ฝึกด้วย seed 42 เพียงชุดเดียว แม้ประเมินแยก 3 กลุ่ม seed ผลยังไม่ใช่ข้อสรุปความคงที่ของการฝึกข้าม seed
- Seeker เห็น Hider ตลอด และได้เดินก่อน จึงได้เปรียบ Hider มาก การรอดครบ 64 ก้าวไม่ใช่ตัวชี้วัดเดียวที่เหมาะกับคู่แข่งแข็งแรง; ควรดูจำนวนก้าวที่ยืดเวลาได้ด้วย
- Hider สุ่มแบบ V1 เลือกเฉพาะทิศที่เดินได้ แต่โมเดล Hider อาจเลือกทิศชนขอบเพื่ออยู่ที่เดิม การเทียบกับ Hider สุ่มจึงไม่ใช่ action distribution เดียวกันทุกสถานะ
- สนามยังไม่มีกำแพง ห้อง หรือการบังสายตา ผลนี้ไม่ยืนยันประสิทธิภาพในสภาพแวดล้อมที่ซับซ้อนกว่า
