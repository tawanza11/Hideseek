# Hide-and-Seek RL V6 — แผนทดลองที่กำหนดก่อนเปิดผล

## คำถาม

การค่อยเพิ่มความหลากหลายของแผนที่ช่วยให้ Seeker จับ Hider บนแผนที่ใหม่ได้ดีกว่าการฝึกด้วยแผนที่ทั้งหมดตั้งแต่แรกหรือไม่ เมื่อทั้งสองแบบใช้คู่แข่งหลายตัวและงบฝึกเท่ากัน

## วิธีฝึกที่ล็อกไว้

- ฝึก PPO แบบไม่มี visit memory และใช้ legal-action filtering เฉพาะตอนประเมิน ทั้งสองแขนเริ่มจาก V4 no-memory seed เดียวกันด้วย optimizer ใหม่
- แขน `flat` ใช้ pool V5 เดิม 108 แผนที่ไม่ซ้ำตั้งแต่ต้น แขน `curriculum` ใช้แผนที่เดิม 8 แผนที่พร้อม V5T 20, 50 และ 100 แผนที่ตามลำดับ แต่ละแขนใช้จำนวนรายการซ้ำของ default และ F1 เหมือน V5
- แบ่งการฝึกเป็น 50,000 + 50,000 + 100,000 ก้าวที่ร้องขอต่อ seed (41, 42, 43) ทั้งสองแขนใช้รางวัล, hyperparameters, seed และคู่แข่ง pool เดียวกัน
- คู่แข่งในแต่ละ episode เลือกหนึ่งตัวจาก Hider สุ่มและ Hider V3 seed 41, 42, 43 ด้วยโอกาสเท่ากัน แล้วตรึงตัวนั้นจนจบ episode; ไม่มีการฝึก Hider เพิ่ม
- V5 Control ที่บันทึกไว้เป็นตัวเทียบเดิม แต่ไม่ใช่ control สำหรับแยกผล curriculum เพราะ V5 ใช้ Hider seed เดียวขณะฝึก

## การวัดและเกณฑ์ที่ล็อกไว้

ประเมินกับ Hider V3 seed ที่จับคู่บน V5E 10 แผนที่ × 3 training seed × 100 เกม และบน default 100 เกมต่อ seed โดยใช้จุดเริ่มเดียวกันกับผล V5 ทั้งสองแขนใช้การเลือกทิศที่เดินได้ตอนประเมิน รายงานผลรวม ราย seed รายแผนที่ และจำนวนช่องที่ไปถึง

จะ **เลื่อน curriculum เป็นตัวเลือก V6** ก็ต่อเมื่อบน V5E จับได้มากกว่า `flat` และ V5 Control อย่างน้อย 2 จุดเปอร์เซ็นต์ทั้งคู่, ดีกว่า `flat` อย่างน้อย 2 ใน 3 training seed, และบน default ได้ไม่น้อยกว่า V4 no-memory ลบ 5 จุดเปอร์เซ็นต์ (V4 อ้างอิง 170/300 = 56.7%) หากไม่ครบ ให้บันทึกว่าไม่มีโมเดล V6 ที่ผ่านเกณฑ์ ไม่เลือกย้อนหลังจากผลรายแผนที่

หลังบันทึกการตัดสินจาก V5E และ default แล้ว จึงเปิด V5F 20 แผนที่ **ครั้งเดียว** ใช้ 100 เกมต่อแผนที่ต่อ training seed และเปรียบเทียบ random, V4, V5 Control, `flat`, `curriculum` ด้วย seed เดียวกัน เกณฑ์เป้าหมายสุดท้ายของตัวเลือก V6 คือผลรวมสูงกว่า random อย่างน้อย 10 จุดเปอร์เซ็นต์, ไม่ต่ำกว่า random ในอย่างน้อย 12/20 แผนที่ และสูงกว่า random ในอย่างน้อย 2/3 training seed หากไม่มีตัวเลือกที่ผ่านเกณฑ์ validation ให้ผล V5F เป็นการวินิจฉัย ไม่อ้างว่าบรรลุเป้าหมาย

V5F ไม่ใช้ฝึก ปรับ hyperparameters หรือเลือก checkpoint ผล F1/F2 เป็นข้อมูลที่เคยเปิดและอยู่ใน pool ฝึก จึงไม่ใช่หลักฐานการทั่วไป
