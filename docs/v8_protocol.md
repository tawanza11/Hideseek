# V8 protocol — ภารกิจปิดทางและปีนข้าม

กำหนดก่อนฝึกเต็มและก่อนดูผล V8E/V8F เพื่อแก้ข้อจำกัดของ V7 โดยยังใช้กติกาการสังเกตของ V7 ที่ทั้งสองฝ่ายเห็นเฉพาะข้อมูลของตัวเอง

## ฉากและข้อมูล

- ฉาก 10×10 เวลา 27 เทิร์น Seeker เดินก่อน Hider; จุดเริ่มกำหนดเป็นคู่ต่อแผนที่เพื่อให้ Hider มีโอกาสผลักบล็อกหนึ่งครั้งปิดทางตรง Seeker ต้องใช้ทางปีนข้ามกำแพงเตี้ยเพื่อเข้าฝั่ง Hider หลังประตูปิด
- ตัวสร้างแผนที่เปลี่ยนตำแหน่งกำแพงขอบห้องและหมุน/สะท้อนรูปแบบ โดยตรวจทุกฉากว่าพื้นที่เดินได้เชื่อมกันก่อนผลัก และหลังผลักต้องมีสองฝั่งที่เชื่อมผ่านทางปีนเท่านั้น
- ฝึก V8T 100 แผนที่, คัดเลือก V8E 10 แผนที่, กัน V8F 20 แผนที่ไว้เปิดครั้งเดียวหลังผ่านเกณฑ์ V8E; ไม่ใช้ V7F ที่ยังปิดผนึก
- ชุด V8E รุ่นแรก fingerprint `af8cda1a7968e5df7beb3f223df061b2b22715e1ad288e298dde42c0bd81b0b1` ถูกเปิดด้วยโมเดล smoke test ก่อนฝึกเต็ม จึง **ยกเลิก** และไม่ใช้เลือกโมเดลหรืออ้างเป็น validation; ชุด V8E ด้านล่างเป็นชุดใหม่ที่สร้างก่อนดูผลโมเดลเต็ม
- Fingerprint: V8T `985410095794e0b85f66bfab01a002a04a32436566a879cd825f2c33be9f9c93`, V8E `857b0c7239ac2cd4268b25316a0e02fd60c98523fe15160a3f88f3216dcae05e`, V8F `39a228af09a010bef8c0750fd3ceac5716cf42cd9c13126bc4e746a1be36ce5e`

## การฝึกที่กำหนดไว้

- ฝึก 3 seed: 41, 42, 43; แต่ละฝ่ายเริ่มจากโมเดล V7 ของ seed เดียวกัน
- Hider: เลียนแบบข้อมูลการผลักบล็อกที่มองเห็นเอง 20,000 ก้าว 5 รอบ แล้ว PPO 100,000 ก้าวที่ขอ กับ Seeker สุ่ม/ตัวค้นหาตามกติกา รางวัลเพิ่ม +0.3 เฉพาะการผลักบล็อกลงช่องปิดประตู
- Seeker: เลียนแบบตัวค้นหาที่ใช้ observation 20,000 ก้าว 5 รอบ แล้ว PPO 100,000 ก้าวที่ขอ กับ Hider ตัวสาธิตที่ผลักปิดประตูแล้วเดินแบบสุ่มที่ถูกกติกา รางวัลเพิ่ม +0.1 เมื่อปีนข้ามกำแพงเตี้ย
- โมเดล Seeker ยังรับคำแนะนำเส้นทาง 8 ค่าจาก observation ของตัวเอง จึงเป็นระบบผสมกติกาหาเส้นทางและ neural policy; Hider ได้สาธิตการผลักแล้วเรียนรู้ต่อด้วย PPO ต้องระบุแหล่งที่มานี้เมื่อรายงาน
- จำนวนก้าวจริงอาจเกินจำนวนที่ขอเล็กน้อยตามขนาด rollout ของ PPO บันทึกจำนวนจริงและ hash โมเดล

## การคัดเลือกบน V8E

- ทุกคู่เล่น 100 เกมต่อแผนที่ต่อ seed (1,000 เกมต่อ seed) จุดเริ่มเดียวกัน นโยบายคู่แข่งที่เดินสุ่มใช้ seed เดียวกันในคู่เปรียบเทียบ นโยบายที่เรียนรู้สุ่มจากความน่าจะเป็นในทิศที่ถูกกติกาเพื่อให้มีหลาย trajectory จากจุดเริ่มเดียวกัน
- Seeker เจอ Hider ตัวสาธิตที่ผลักปิดประตูแล้วเดินสุ่ม: ต้องจับได้มากกว่า Seeker สุ่มอย่างน้อย 100/1,000 เกม และไม่ต่ำกว่าในอย่างน้อย 7/10 แผนที่
- Hider เจอ Seeker ตัวค้นหาตามกติกา: ต้องรอดมากกว่า Hider สุ่มอย่างน้อย 100/1,000 เกม และไม่ต่ำกว่าในอย่างน้อย 7/10 แผนที่
- ผลวัตถุจับคู่ game seed: Seeker เปิดวัตถุครบต้องจับได้มากกว่าปิดทางปีนอย่างน้อย 100/1,000 เกมและปีน ≥20 ครั้ง; Hider เปิดวัตถุครบต้องรอดมากกว่าปิดบล็อกอย่างน้อย 100/1,000 เกมและผลัก ≥20 ครั้ง เงื่อนไขแต่ละฝ่ายต้องผ่านใน 2/3 seed
- จะเปิด V8F เมื่อเกณฑ์การเล่นพื้นฐานและวัตถุผ่านครบทั้งสองฝ่าย ล็อก CSV และ hash โมเดลก่อนเปิด หากไม่ผ่าน ให้เก็บผลล้มเหลวและไม่เปิด V8F
- ตรวจผลย้อนหลังบน V7E แยกต่างหากเพื่อรายงานการถดถอยของความสามารถทั่วไป ไม่ใช้ V7E ปรับเกณฑ์ V8E และไม่อ้างว่ารุ่น V8 แทน V7 ในทุกฉากหากผลย้อนหลังแย่ลง
